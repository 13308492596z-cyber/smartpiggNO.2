# 行迹 · iPhone 本机路线测试（试验版）

这是供 TrollStore 环境验证的 iOS 16 原型工程，已通过 GitHub macOS 编译和路线计算检查，尚未安装到 XR 或验证本机系统定位。此前的电脑 USB 测试成功不代表本工程已经能独立运行。

## 功能实现

沿用原地图编辑界面，提供地图绘点、闭合路线、WGS84 坐标导入、距离、时长、预览、起点、倒计时、暂停、继续、恢复与 GPX 分享。本机 Objective-C 模块调用 CLSimulationManager，将完整场景交给系统定位服务；进度为按计划时间计算的估计值，不是目标应用认可的里程，也不是系统位置回读。

界面由安装包内 WKWebView 承载，本机模块直接执行定位操作，不连接此前电脑端的 8765 服务。地图瓦片需要网络。起始地图为全国视图，个人路线由用户在手机上输入或导入。

模拟开始前持久化恢复标记；重新打开遇到未恢复状态时只允许恢复，不自动续跑。倒计时期间切换应用会取消倒计时。整段轨迹是否在切回微信后持续按时间运行、定位服务是否接受权限、终点保持行为及恢复效果，均需 XR 实机测试。

## 编译

需要 macOS、Xcode command-line tools 和 ldid，可使用 GitHub Actions 的 macos-15 runner。执行 `bash build.sh`：先编译运行纯 C 路线检查，再编译 arm64 iOS 16 程序、附加 TrollStore 所需权限并输出 `build/RouteLab-iPhone-0.1.0.tipa`。

云端工作流仅支持手动触发，不会因上传代码自动构建。私有仓库的 Actions 会使用账户额度；构建前应确认可用额度。编译不需要 Apple 账户密码、签名证书、设备配对文件或个人路线。

## 安装条件

普通 Apple 签名侧载不能授予本工程要求的私有定位权限。候选安装路径是先在 Windows 完成 TrollInstallerX 的首次签名侧载，再安装 TrollStore，最后用 TrollStore 安装测试包。安装 TrollStore 涉及系统漏洞与持久化助手，需要用户明确同意进入实际安装阶段。当前阶段仅完成了可行性研究和源码整理。

## 验证状态

- Windows 只能检查资源、JavaScript 语法、plist 结构、源码引用等静态内容；原生编译已在 GitHub macOS runner 成功完成，详情见 BUILD-STATUS.md。
- `tests/RouteMathTests.c` 已在 macOS 构建中通过，覆盖闭合循环连续性、开放路线拒绝重复、非法坐标、时间范围与跨日期变更线插值。
- 首次实机验证应在自带地图中完成起点、短路线、切后台、暂停与恢复检查，再检查其他应用是否读取到一致位置。
